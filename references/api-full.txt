### Script location

Every script is stored in your `AppData/Roaming` in the `scripts` folder. \
After adding a new `.as` file please close and reopen the menu to refresh the list of scripts.\
Example location: `C:\Users\username\AppData\Roaming\scripts`

### Language

[AngelScript](https://www.angelcode.com/angelscript/) is a C-style scripting language with syntax close to C++, designed to be embedded in applications and run at runtime. It pairs the comfort of a statically typed language with the flexibility of a script you can load and reload on the fly, while object handles and reference counting manage memory for you. For the complete language reference, see the official [AngelScript documentation](https://www.angelcode.com/angelscript/sdk/docs/manual/doc_script.html).

### **Entrypoint**

Every script must define `bool main()`. It's the entry point, and a script won't compile without it. Return `true` for success, or `false` to signal failure, which unloads the script.

`on_unload()` is optional and runs when the script is unloaded. Use it for teardown like saving data, releasing external resources, or undoing any modifications made to the target process. You don't need to manually clear global arrays, handles, or other script objects, since reference counting cleans those up automatically when the script unloads.

```cpp
void on_unload() {
    // ...
}

bool main() {
    // ...
    return true;
}
```

#### Mutexes

```cpp
// Create a mutex for thread synchronization
mutex@ create_mutex();

// mutex methods
mutex.lock();          // Acquire exclusive lock (blocks until available)
mutex.unlock();        // Release exclusive lock
mutex.try_lock();      // Try to acquire exclusive lock without blocking — returns bool
mutex.lock_shared();   // Acquire shared lock (multiple readers allowed simultaneously)
mutex.unlock_shared(); // Release shared lock
```

#### Atomics

```cpp
// Atomic types — lock-free thread-safe primitives
// Operations use acquire/release memory ordering
atomic_bool@ atomic_bool(bool value);
atomic_int32@ atomic_int32(int value);
atomic_uint32@ atomic_uint32(uint value);
atomic_int64@ atomic_int64(int64 value);
atomic_uint64@ atomic_uint64(uint64 value);
atomic_float@ atomic_float(float value);
atomic_double@ atomic_double(double value);

.load();          // Returns the current value.
.store(value);    // Updates value.
.exchange(value); // Updates value, returns the previous value.

// Atomically compares current value to expected - writes desired if they match.
// Returns observed value (equals expected on success, differs on failure).
.compare_exchange(expected, desired); -> T
```

#### First time using threads

`main()` is where threads get set up. `create_thread(tps, cb)` runs a callback at a fixed tick rate, and `on_render(cb)` runs one on the render path. Each thread keeps calling its callback, so anything they share needs guarding.

The example below runs a few threads at different rates, each touching shared state a different way: a counter behind a mutex, the same counter using `try_lock` so it never blocks, and a lock-free atomic counter. The render thread reads both and prints them every frame.

```cpp
mutex@ g_mutex = create_mutex();
int g_shared_counter = 0;
atomic_int32@ g_atomic_counter = atomic_int32(0);

void fast_tick() {
    g_mutex.lock();
    g_shared_counter++;
    g_mutex.unlock();
}

void slow_tick() {
    if (g_mutex.try_lock()) {
        g_shared_counter++;
        g_mutex.unlock();
    } 
    else {
        print("lock is busy");
    }
}

void render_tick() {
    g_mutex.lock_shared();
    int shared = g_shared_counter;
    g_mutex.unlock_shared();

    int atomic = g_atomic_counter.load();
    print("shared: " + shared + " atomic: " + atomic);
}

// Safe only because this is the single writer of g_atomic_counter.
// A real read-modify-write across threads needs compare_exchange (see Atomics).
void atomic_tick() {
    g_atomic_counter.store(g_atomic_counter.load() + 1);
}

bool main() {
    create_thread(128, @fast_tick);
    create_thread(32, @slow_tick);
    create_thread(64, @atomic_tick);
    on_render(@render_tick);
    return true;
}
```

#### Sharing data between threads

**Sharing data can be dangerous**

**Unsynchronized global access.** Two threads sharing and updating the same global with no lock can race on the AngelScript engine internal state taking the entire process down with it.

**Torn reads.** One thread reads an object while another is partway through updating it. The reader ends up with a mix of old and new values, say the new frame number but the old positions. The object is now in a state the reading code assumes can never happen.\
\
**How object handles make this easy**

A handle in AngelScript is a counted reference to an object. The object stays alive as long as something holds a handle to it. Once the last handle goes away its reference count drops to zero and the object is reclaimed immediately. Copying a handle doesn't copy the object, it just points another reference at the same one and bumps the count.

This makes a one-writer, many-reader setup easy. Readers each hold their own handle to the current snapshot, and the writer swaps in a new one without disturbing them.

```cpp
interface snapshot_t {}

class shared_snapshot {
    private snapshot_t@ current;
    private mutex@ mtx;

    shared_snapshot(snapshot_t@ initial) {
        @current = initial;
        @mtx = create_mutex();
    }

    // Publish a finished snapshot.
    // Build it fully before calling this, then leave it alone.
    // The swap takes an exclusive lock, so it briefly blocks readers,
    // but only for the handle swap, never while a reader reads snapshot contents.
    void publish(snapshot_t@ next) {
        mtx.lock();
        @current = next;
        mtx.unlock();
    }

    // Hand back a reference to the current snapshot.
    // The returned handle keeps that snapshot alive on its own.
    // The caller can read it freely afterwards without holding any lock.
    snapshot_t@ acquire() {
        mtx.lock_shared();
        snapshot_t@ snap = current;
        mtx.unlock_shared();
        return snap;
    }
}

class entity {
    string name;
    int health;
    int max_health;
    vec3 world_pos;
    int team_id;
}

// One frame's worth of entities.
class game_snapshot : snapshot_t {
    array<entity@> entities;
}

shared_snapshot@ g_state;

// Set up the shared state once before any thread reads it.
void init() {
    @g_state = shared_snapshot(game_snapshot());
}

// Writer: build a fresh snapshot each tick, then publish it.
void writer() {
    game_snapshot next;

    entity player_1;
    player_1.name = "Peter";
    player_1.health = 100;
    player_1.max_health = 100;
    player_1.world_pos = vec3(0.0f, 0.0f, 0.0f);
    player_1.team_id = 0;
    next.entities.insertLast(player_1);

    entity player_2;
    player_2.name = "John";
    player_2.health = 75;
    player_2.max_health = 100;
    player_2.world_pos = vec3(0.0f, 0.0f, 0.0f);
    player_2.team_id = 0;
    next.entities.insertLast(player_2);

    entity player_3;
    player_3.name = "Judas";
    player_3.health = 50;
    player_3.max_health = 100;
    player_3.world_pos = vec3(0.0f, 0.0f, 0.0f);
    player_3.team_id = 1;
    next.entities.insertLast(player_3);

    g_state.publish(next);
}

// Reader: grab the current snapshot, cast to the real type, then read freely.
void reader() {
    game_snapshot@ snap = cast<game_snapshot>(g_state.acquire());
    if (snap is null) {
        return;
    }

    // no lock held here
    for (uint i = 0; i < snap.entities.length(); i++) {
        entity@ e = snap.entities[i];
        print(e.name + " [team " + e.team_id + "]");
        print("hp: " + e.health + "/" + e.max_health);
        print("pos: (" + e.world_pos.x + ", " + e.world_pos.y + ", " + e.world_pos.z + ")");
    }
}
```

# Zydis Disasm

Bindings for Zydis the x86-64 disassembler. Decoded instructions are returned as reference-counted disasm\_insn handles; operands are value-type disasm\_operand structs.

#### Types

```cpp
// operand type
op_type::unused
op_type::reg
op_type::mem
op_type::ptr
op_type::imm

// operand visibility
op_visibility::invalid
op_visibility::explicit
op_visibility::implicit
op_visibility::hidden

// operand action flags
op_action::read
op_action::write
op_action::readwrite
op_action::condread
op_action::condwrite
op_action::read_condwrite
op_action::condread_write

struct disasm_operand {
    int type;            // op_type value
    int visibility;      // op_visibility value
    int action;          // op_action bitmask
    int reg;             // valid when type == op_type::reg; pass to zydis::reg_name()
    bool imm_is_signed;  // valid when type == op_type::imm
    bool imm_is_relative;
    uint64 imm_value;
    int mem_segment;     // valid when type == op_type::mem
    int mem_base;
    int mem_index;
    uint8 mem_scale;
    int64 mem_disp;
    bool mem_has_disp;
}

// reference counted; returned in output array by disasm / disasm_func
struct disasm_insn {
    uint64 runtime_address; // base address; rip-relative operands resolve against this
    uint8 length;           // encoded byte length
    int mnemonic;           // raw Zydis mnemonic id
    string text;            // Intel-syntax disassembly
    uint8 operand_count;    // includes implicit and hidden operands
    uint8 operand_count_visible;
    
    // returns default operand if idx is out of range
    disasm_operand get_op(uint8 idx) const;
}
```

#### Usage example

```cpp
void print_simple(disasm_insn@ insn) {
    print(insn.text);
}

void print_detailed(disasm_insn@ insn) {
    print("[" + util::to_hex(insn.runtime_address) + "] " + insn.text + " [len=" + insn.length + " ops=" + insn.operand_count_visible + "]\n");

    for (uint8 j = 0; j < insn.operand_count_visible; j++) {
        disasm_operand op = insn.get_op(j);
        string s = "op[" + j + "] ";

        switch (op.type) {
        case op_type::reg: {
            s += "reg=" + zydis::reg_name(op.reg);
            break;
        }
        case op_type::imm: {
            s += "imm=" + util::to_hex(op.imm_value);
            if (op.imm_is_relative) {
                s += " (rel)";
            }
            if (op.imm_is_signed) {
                s += " (signed)";
            }
            break;
        }
        case op_type::mem: {
            s += "mem [";
            if (op.mem_base != 0) {
                s += "base=" + op.mem_base + " ";
            }
            if (op.mem_index != 0) {
                s += "index=" + op.mem_index + " scale=" + op.mem_scale + " ";
            }
            if (op.mem_has_disp) {
                s += "disp=" + util::to_hex(uint64(op.mem_disp));
            }
            s += "]";
            break;
        }
        }

        print(s);
    }
}

bool main() {
    if (process::attach("process_name.exe").pid == 0) {
        print("failed to attach to process");
        return false;
    }

    uint64 ntdll = process::get_module_base("ntdll.dll");
    if (ntdll == 0) {
        print("failed to get ntdll base");
        return false;
    }

    uint64 target = process::get_module_export(ntdll, "NtCreateFile");
    if (target == 0) {
        print("failed to find NtCreateFile");
        return false;
    }

    array<uint8>@ bytes = process::read_bytes(target, 256);
    if (bytes is null) {
        print("failed to read bytes");
        return false;
    }

    array<disasm_insn@> insns;
    if (!zydis::disasm_func(bytes, target, insns)) {
        print("disassembling failed");
        return false;
    }

    print("NtCreateFile");
    for (uint32 i = 0; i < insns.length(); i++) {
        print_simple(insns[i]);
    }

    print(""); // Seperator
    print("Detailed output:");
    for (uint32 i = 0; i < insns.length(); i++) {
        print_detailed(insns[i]);
    }

    return true;
}
```

# Unicorn Emulator

Bindings for the Unicorn CPU emulator

Note: Emulator handles are opaque `uint64` values returned by `uc::create()` or `uc::create_process()` - a handle of `0` means creation failed. Call `uc::close(h)` when you're done to release memory mappings and hooks; any handles left open are automatically cleaned up on script unload. The emulator is x86\_64 - there is no mode parameter, and all register access goes through `x86_reg`.

```cpp
// with correct Win32 protection flags; if a region overlaps an already-mapped area, only the faulting
// page is mapped instead. write faults to unmapped regions are not auto-mapped and will stop emulation.

// stop a running emulation from within a hook

// last error code and fault address after a failed start()

uint64 uc::fault_address(uint64 h);
```

#### Pointer decryption

```cpp
bool main() {
    uint64 h = uc::create();
    if (h == 0) {
        return false;
    }

    const uint64 code_base = 0x1000;
    const uint64 stop_base = 0x2000;

    uc::mem_map(h, code_base, 0x1000, uc::prot::read | uc::prot::exec);
    uc::mem_map(h, stop_base, 0x1000, uc::prot::read | uc::prot::exec);
    uc::setup_stack(h, 0x10000, 0x2000, stop_base);

    // ror(ptr ^ key, 0x11)
    array<uint8> code = {
        0x49, 0xb8, 0xef, 0xbe, 0xad, 0xde, 0x00, 0x00, 0x00, 0x00, // mov r8, 0xdeadbeef
        0x4c, 0x33, 0xc0,                                           // xor rax, r8
        0x48, 0xc1, 0xc8, 0x11,                                     // ror rax, 17
        0xc3                                                        // ret
    };
    uc::mem_write(h, code_base, code);

    uint64 encrypted = 0x4f6e3a2b1c0d9e8f;
    uc::reg_write64(h, x86_reg::rax, encrypted);

    int result = uc::start(h, code_base, stop_base);
    if (result != uc::error::ok) {
        uc::close(h);
        return false;
    }

    uint64 decrypted = 0;
    uc::reg_read64(h, x86_reg::rax, decrypted);
    print("encrypted: 0x" + formatInt(encrypted, "0H", 16));
    print("decrypted: 0x" + formatInt(decrypted, "0H", 16));

    uc::close(h);
    return true;
}
```

#### PEB module enumeration

```cpp
bool main() {
    if (process::attach("process_name.exe", false).pid == 0) {
        print("process not found");
        return false;
    }

    uint64 h = uc::create_process();
    if (h == 0) {
        return false;
    }

    uc::mem_map(h, 0x1000, 0x3000, uc::prot::all);
    uc::setup_stack(h, 0x4000, 0x2000, 0x6000);

    // gs:[0x60] -> PEB -> Ldr -> &InLoadOrderModuleList (sentinel in rcx, first entry in rdi)
    array<uint8> stub_init = {
        0x65, 0x48, 0x8B, 0x04, 0x25, 0x60, 0x00, 0x00, 0x00, // mov rax, gs:[0x60]
        0x48, 0x8B, 0x40, 0x18,                               // mov rax, [rax+0x18]
        0x48, 0x8D, 0x40, 0x10,                               // lea rax, [rax+0x10]
        0x48, 0x89, 0xC1,                                     // mov rcx, rax
        0x48, 0x8B, 0x38,                                     // mov rdi, [rax]
        0xC3
    };

    // rdi = LDR_DATA_TABLE_ENTRY, reads DllBase/EntryPoint/SizeOfImage, advances rdi to next entry
    array<uint8> stub_read = {
        0x48, 0x8B, 0x47, 0x30, // mov rax, [rdi+0x30]
        0x48, 0x8B, 0x5F, 0x38, // mov rbx, [rdi+0x38]
        0x8B, 0x4F, 0x40,       // mov ecx, [rdi+0x40]
        0x48, 0x8B, 0x3F,       // mov rdi, [rdi]
        0xC3
    };

    uc::mem_write(h, 0x1000, stub_init);
    uc::mem_write(h, 0x2000, stub_read);

    uc::start(h, 0x1000, 0x6000);
    uint64 sentinel = 0;
    uint64 flink = 0;
    uc::reg_read64(h, x86_reg::rcx, sentinel);
    uc::reg_read64(h, x86_reg::rdi, flink);

    int idx = 0;
    while (flink != sentinel && flink != 0) {
        uc::reg_write64(h, x86_reg::rdi, flink);
        uc::start(h, 0x2000, 0x6000);

        uint64 dll_base = 0;
        uint64 entry_point = 0;
        uint64 size_of_image = 0;
        uint64 next = 0;
        uc::reg_read64(h, x86_reg::rax, dll_base);
        uc::reg_read64(h, x86_reg::rbx, entry_point);
        uc::reg_read64(h, x86_reg::rcx, size_of_image);
        uc::reg_read64(h, x86_reg::rdi, next);

        print("[" + idx + "] DllBase: 0x" + formatInt(dll_base, "0H", 16) + " EntryPoint: 0x" + formatInt(entry_point, "0H", 16) + " SizeOfImage: 0x" + formatInt(size_of_image, "0H", 8));

        flink = next;
        idx++;
    }

    uc::close(h);
    return true;
}
```

```cpp
bool main() {
    // alice builds a message
    json_obj@ msg = json_obj();
    msg.set("from", "alice");
    msg.set("to", "bob");
    msg.set("text", "meet me at midnight");
    msg.set("encrypted", false);
    msg.set("attempts", 1);
    msg.set("confidence", 0.98f);
    msg.set_null("session_key");

    json_obj@ ciphers = json::array();
    ciphers.push("aes-256");
    ciphers.push("rsa-2048");
    msg.set("ciphers", ciphers);

    print("alice sends:");
    print(json::stringify(msg, true));

    // bob receives it
    string err;
    json_obj@ received = json::parse(json::stringify(msg), err);
    if (received is null)
    {
        print("parse failed: " + err);
        return false;
    }

    // bob reads each field
    array<string>@ keys = received.keys();
    print("bob reads:");
    for (uint i = 0; i < keys.length(); i++)
    {
        string k = keys[i];
        json_type t = received.type(k);
        switch (t)
        {
        case json_type::string:
            print(k + ": \"" + received.get_string(k) + "\"");
            break;
        case json_type::number:
            print(k + ": " + received.get_float(k));
            break;
        case json_type::boolean:
            print(k + ": " + received.get_bool(k));
            break;
        case json_type::null_value:
            print(k + ": null");
            break;
        case json_type::array:
        {
            json_obj@ arr = received.get_obj(k);
            for (uint j = 0; j < arr.length(); j++)
            {
                print(k + "[" + j + "]: \"" + arr.get_string_at(j) + "\"");
            }
            break;
        }
        }
    }

    // bob replies with a session key
    json_obj@ reply = json_obj();
    reply.set("from", "bob");
    reply.set("to", "alice");
    reply.set("text", "understood");
    reply.set("encrypted", true);
    reply.set("cipher", "aes-256");
    reply.set("session_key", "f3a1b9c2");
    reply.set("confidence", 1.0f);

    print("bob replies:");
    print(json::stringify(reply, true));

    return true;
}
```

# Async HTTP

Requests are non-blocking — instead of returning a value directly, you pass a callback function.

```cpp
// Requests are asynchronous and only callable from main().
// User-agent: prism/1.0
// Timeout: 10s
// Redirects are followed automatically.

struct http_response {
    int status_code;
    string body;
    string error;
}

// callback funcdef
void response_callback(http_response@ response) {}

// Async HTTP - fires request on a background thread, invokes callback on completion.
// Only callable from main().
void http::get(string url, response_callback@ cb);
void http::post(string url, string body, string content_type, response_callback@ cb);

// Fire-and-forget requests: no callback, no response.
// Callable from any context, including on_unload().
// Intended for webhooks and one-way notifications where you don't need a response.
void http::get(string url);
void http::post(string url, string body, string content_type);
```

#### Usage example

```cpp
void on_response(http_response@ res) {
    if (res.error != "") {
        print("GET error: " + res.error);
        return;
    }

    print("GET status: " + res.status_code);
    print(res.body);
}

bool main() {
    // Named callback
    http::get("https://httpbin.org/get", @on_response);

    // Inline callback
    http::post("https://httpbin.org/post", "{\"hello\": \"world\"}", "application/json", function(http_response@ res) {
        if (res.error != "") {
            print("POST error: " + res.error);
            return;
        }

        print("POST status: " + res.status_code);
        print(res.body);
    });

    return true;
}
```

```cpp
clip_paths@ clip_paths.clone();

// boolean operation against another set of paths, mutates this object
void clip_paths.boolean_op(
    clip_paths@ clips,
    clip_type,
    fill_rule = NON_ZERO
);

// inflate (outset) or deflate (inset) all paths by delta units
// use ET_POLYGON for closed polygons, ET_BUTT/ET_ROUND for open polylines
// join_type controls how corners are handled
void clip_paths.inflate(
    double delta,
    join_type = ROUND,
    end_type = ET_POLYGON
);

// simplify paths by removing vertices 
// within epsilon distance of their neighbors
void clip_paths.simplify(double epsilon = 0.1);

// merge all overlapping paths within the object into a single set
// useful for cleaning up self-intersecting or overlapping input before drawing
void clip_paths.union_self(fill_rule = NON_ZERO);
```

#### Example

```cpp
void render_tick() {
    array<vec2> outer_rect = {
        vec2(100, 100),
        vec2(200, 100),
        vec2(200, 200),
        vec2(100, 200)
    };
    
    array<vec2> inner_rect = {
        vec2(150, 150),
        vec2(250, 150),
        vec2(250, 250),
        vec2(150, 250)
    };

    clip_paths@ paths = clip_paths();
    clip_paths@ cutout = clip_paths();
    paths.add_path(outer_rect);
    cutout.add_path(inner_rect);
    paths.boolean_op(cutout, DIFFERENCE);

    for (uint i = 0; i < paths.path_count(); i++) {
        render::draw_polyline(paths.get_path(i), 255, 255, 0, 255, 1.0f, true);
    }
}

bool main() {
    on_render(@render_tick);
    return true;
}
```


# Tracing

Ray and geometry intersection utilities, including a BVH tree for fast occlusion queries.

#### Registered types

```cpp
struct triangle {
    vec3 p1;
    vec3 p2;
    vec3 p3;
}
```

#### **BVH Tree**

```cpp
// ref-counted BVH tree for ray occlusion queries
// add triangles, call build(), then query with is_occluded()
// thread-safe: multiple threads may call is_occluded() concurrently
// any mutation invalidates the tree until build() is called again

// returns null on allocation failure
bvh_tree@ create_bvh_tree();

// add one or more triangles to the tree
void bvh_tree.add_triangle(const vec3 &in p1, const vec3 &in p2, const vec3 &in p3);
void bvh_tree.add_triangles(const array<triangle> &in tris);

// build the tree, returns false if no triangles have been added
bool bvh_tree.build();

// returns true if the segment from->to is blocked by any triangle
// returns false if the tree is not built
bool bvh_tree.is_occluded(const vec3 &in from, const vec3 &in to);

// remove all triangles and nodes
// resets tree to an unbuilt state
void bvh_tree.clear();

// returns the number of triangles in the tree
uint64 bvh_tree.triangle_count();

// returns true if build() has been called and no mutations have occurred since
bool bvh_tree.is_ready();
```

#### **One-off intersection tests**

```cpp
// Moller-Trumbore intersection, returns true if the ray hits the triangle within max_t
bool trace::ray_triangle(
    const triangle &in tri,
    const vec3 &in origin,
    const vec3 &in dir,
    double max_t
);

// Slab method AABB intersection, returns true if the ray hits the box within max_t
bool trace::ray_bbox(
    const vec3 &in origin,
    const vec3 &in dir,
    const vec3 &in box_min,
    const vec3 &in box_max
    double max_t,
);

// Analytic sphere intersection, returns true if the ray hits the sphere within max_t
bool trace::ray_sphere(
    const vec3 &in origin,
    const vec3 &in dir,
    const vec3 &in center,
    double radius,
    double max_t
);

// Closest-point capsule intersection, returns true if the ray hits the capsule within max_t
// cap_min and cap_max are the two endpoint centers of the capsule axis
bool trace::ray_capsule(
    const vec3 &in origin,
    const vec3 &in dir,
    const vec3 &in capsule_min,
    const vec3 &in capsule_max,
    double radius,
    double max_t
);
```

#### **Example: Occlusion query**

```cpp
bool main() {
    bvh_tree@ tree = create_bvh_tree();

    tree.add_triangle(
        vec3(-100.0, 0.0, -100.0), 
        vec3(100.0, 0.0, -100.0), 
        vec3(0.0, 0.0, 100.0)
    );

    if (!tree.build()) {
        return false;
    }

    vec3 camera_pos = vec3(0.0, 10.0, 0.0);
    vec3 target_pos = vec3(0.0, 0.0, 0.0);

    if (tree.is_occluded(camera_pos, target_pos)) {
        print("target is behind geometry");
    } 
    else {
        print("target is visible");
    }

    return true;
}
```

#### **Example: Bulk load from mesh data**

```cpp
bool main() {
    bvh_tree@ tree = create_bvh_tree();

    array<triangle> tris;
    tris.insertLast(triangle(vec3(-1.0, 0.0, 0.0), vec3(1.0, 0.0, 0.0), vec3(0.0, 1.0, 0.0)));
    tris.insertLast(triangle(vec3(-1.0, 0.0, 1.0), vec3(1.0, 0.0, 1.0), vec3(0.0, 1.0, 1.0)));
    tree.add_triangles(tris);
    tree.build();
    return true;
}
```
